### Математическая часть

Вычисления производятся в конечном поле Галуа по модулю неприводимого многочлена из индивидуального варианта: $p(x) = x^8 + x^5 + x^3 + x + 1$ (в шестнадцатеричном виде: 0x12B). 

* **Операция сложения:** Выполняется как побитовое исключающее ИЛИ (XOR) между коэффициентами элементов.
* **Операция умножения:** Реализована на базе алгоритма shift-and-XOR. При переполнении промежуточных разрядов степень полинома своевременно редуцируется по маске неприводимого многочлена, что исключает потерю значащих битов на любых шагах умножения степеней до 14.
* **Мультипликативная инверсия:** Вычисляется через алгоритм быстрого возведения элемента в степень 254 в соответствии с малой теоремой Ферма для конечных полей характеристики 2.

---

### Анализ безопасности и защита Constant-time

* **Отказ от динамической памяти:** Для обеспечения безопасности матрицы состояния, ключевые элементы и рабочие буферы размещены строго в непрерывных блоках памяти фиксированного размера (на стеке). Исключение кучи ликвидирует непредсказуемые задержки распределителя памяти и промахи кэша процессора.
* **Обработка нулевого элемента:** Пограничный случай вычисления обратного значения для нуля (0x00) обрабатывается без условных ветвлений с помощью битового маскирования, гарантируя безопасный переход нуля в самого себя без деления на ноль.
* **Порядок байт:** Формирование блоков счетчика и перемножение полиномов в GHASH полностью синхронизированы по байтовому представлению в формате Big-Endian, как требуют стандарты криптографических режимов.
* **Атака ранним выходом:** Метод проверки подлинности тегов целостности аккумулирует разность побайтово через битовые операции без операторов прерывания цикла, что делает время выполнения процедуры верификации неизменным.
